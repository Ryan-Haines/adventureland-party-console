# Combat retargeting failure inventory

Recorded before the retargeting change. A new target or healer must retire the
previous combat-owned direct segment, detour, heading and progress timers. It
must not cancel an unrelated navigation destination. A fixed target should keep
its selected open-side approach; a moved target must invalidate an obsolete goal.
Attack receipts against a second native target, collision-checked waypoints and
native position/status screenshots must demonstrate resumed engagement.

Keep healing and monster safety constraints for ranged characters, priests,
attacked melee fighters and melee fighters below 60% HP. The temporary coverage
exception belongs only to a healthy, unattacked melee fighter's local detour.
