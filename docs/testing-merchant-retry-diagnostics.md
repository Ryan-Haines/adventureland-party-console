# Merchant retry diagnostics

Failure inventory: recoverable upgrade uncertainty appears informational instead
of red; a generic pause hides item, source/target tier and inventory slot; a
relative retry statement disagrees with the durable retryAt; local formatting
omits timezone; duplicate admission logs falsely promise another retry.

The console scenario declares a worker's uncertain upgrade receipt at the private
worker boundary. Actual coordinator order admission, retry scheduling, and browser
rendering remain real. Require error severity, the supplied item/tier/slot
diagnostic, authoritative retryAt rendered in explicit UTC, and computed red text
with a screenshot/state artifact. Native inventory adoption is tested separately.
